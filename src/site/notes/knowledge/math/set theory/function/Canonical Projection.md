## Definition

> [!definition] Canonical Projection
> If $\sim$ is an [[knowledge/math/set theory/relation/Equivalence Relation\|Equivalence Relation]] on a set $A$, there is a canonical projection
> $$A \twoheadrightarrow A/_\sim$$
> obtained by sending every $a \in A$ to its equivalence class $[a]_\sim$.
