## Definition

> [!definition] Inclusion Function
> For [[knowledge/math/set theory/Set\|Set]] $A \subseteq B$, the **inclusion function** is the [[knowledge/math/set theory/Function\|Function]] $\iota$:
> $$\iota: A \rightarrow B, \quad \iota(x) = x.$$

> [!remark] Alternative Name
> An inclusion function may also be referred as an **inclusion map**, an **insertion**, or a **canonical injection**.
