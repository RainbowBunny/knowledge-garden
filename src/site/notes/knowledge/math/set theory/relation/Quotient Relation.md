## Definition

> [!definition] Quotient Relation
> The **quotient** of the set $S$ with respect to the [[knowledge/math/set theory/relation/Equivalence Relation\|Equivalence Relation]] $\sim$ is the set $S / _\sim$ of equivalence classes of elements of $S$ with respect to $\sim$.
