## Definition

> [!definition] Set
> A **set** is a collection of things (elements), the collection being regarded as a single object.

> [!definition] Membership
> Denote $t \in A$ to say that $t$ is a member of $A$, and $t \notin A$ to say that $t$ is not a member of $A$.

### Disjoint

> [!definition] Disjoint
> Requires:: [[knowledge/math/set theory/Axiom of Set Theory\|Axiom of Set Theory]].
> 
> ---
> Two sets $A$ and $B$ are **disjoint** if $A \cap B = \emptyset$.
