## Definition

> [!definition] Parameters
> - $A, B$: [[knowledge/math/set theory/Set\|sets]].

> [!definition] Category $\mathsf{Set}$
> Instantiates:: [[knowledge/math/algebra/category/Category\|Category]].
>
> ---
> Category $\mathsf{Set}$ consists of
> - $\mathsf{Obj}(\mathsf{Set})$ is the class of all sets.
> - For $A, B$ sets, we define
> $$\mathsf{Hom}_\mathsf{Set}(A, B) = B^A,$$
> the set of [[knowledge/math/set theory/Function\|functions]] $A \to B$.
>
> `[Alu I.3.2]` `[Rie Ex 1.1.3(i)]`

## Property

> [!proposition] Coproduct in Set — the disjoint union
> The disjoint union is a [[knowledge/math/algebra/category/Categorical Coproduct\|Coproduct]] in $\mathsf{Set}$. `[nLab]`
