## Basic Definition

> [!definition] Gaussian Function
> For any $r > 0$, the Gaussian function with parameter $r$ and for any $\mathbf{x} \in \mathbb R^n$ is defined as
> $$\rho_r(\mathbf{x}) = \exp(-\pi||\mathbf{x}||^2/r^2)$$

> [!definition] Sum of Gaussian Function over Countable Set
> $$\rho_r(S) = \sum_{x \in S} \rho_r(\mathbf{x})$$
