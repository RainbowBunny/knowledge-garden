## Definition

> [!definition] Inverse Element
> ### Scope
> A [[knowledge/math/set theory/operation/Binary Operation\|Binary Operation]] $*: O \times O \rightarrow O$.
> 
> ---
> ### Property
> An operation $*$ has [[knowledge/math/property/operation/Identity Element\|Identity Element]] $e$ satisfies inverse element iff 
> $$\forall x \in O \;\exists\; x^{-1} \in O: x * x^{-1} = x^{-1} * x = e$$
