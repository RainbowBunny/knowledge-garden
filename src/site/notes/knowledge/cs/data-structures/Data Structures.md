## Basic Definition

> [!definition] Data Structures
> A **data structure** is a way to store and organize data in order to facilitate access and modifications.

> [!remark]
> We need to study data structure because no single data structure works well for all purposes, and so it is important to know the strengths and limitations of several of them.
