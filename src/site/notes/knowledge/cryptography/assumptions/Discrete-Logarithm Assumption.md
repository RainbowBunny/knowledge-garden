## Parameters

> [!definition] Parameters
> - [[knowledge/complexity/problem/group/Discrete Logarithm Problem\|Discrete Logarithm Problem]]: Import $(\mathbb G, g)$ and the function $\mathrm{Dlog}_g$, with $\mathbb G = \langle g \rangle$ of prime order $q$; the description of $\mathbb G$ includes $q$ and $g$.
> - $\mathcal A$: an efficient [[knowledge/cryptography/foundations/Adversary\|Adversary]], one stateful interactive machine ([[knowledge/cryptography/foundations/Security Game\|Security Game]]).

## Distribution

> [!definition] DL Distribution
> Requires:: [[knowledge/complexity/problem/group/Discrete Logarithm Problem\|Discrete Logarithm Problem]].
>
> ---
> Sampling experiment $\mathrm{DL}(\mathbb G, g)$:
> 1. $\alpha \xleftarrow{\$} \mathbb Z_q$.
> 2. $u \leftarrow g^\alpha$.
> 3. Returns the instance $u$ and the solution $\alpha = \mathrm{Dlog}_g(u)$.
>
> The [[knowledge/complexity/problem/group/Discrete Logarithm Problem\|Discrete Logarithm Problem]] fixes no distribution; the assumption fixes one, through an instance generator run on the security parameter `[Gal12 §20.1]`.

## Problem

### Search Variant

> [!definition] Search DL
> A search game: one branch; the challenger checks the answer in the last row.
>
> | | challenger $\mathcal C$ | | adversary $\mathcal A$ |
> | --- | --- | --- | --- |
> | 1 | $(u, \alpha) \leftarrow \mathrm{DL}(\mathbb G, g)$ | $\xrightarrow{\ \mathbb G,\, u\ }$ | |
> | 2 | | $\xleftarrow{\ \hat\alpha\ }$ | outputs some $\hat\alpha \in \mathbb Z_q$ |
> | 3 | checks whether $\hat\alpha = \alpha$ | | |
>
> **Goal** — $\mathcal A$ wins iff:
> - $\hat\alpha = \alpha$.
>
> $$\mathsf{Adv}^{\mathsf{dl}}_{\mathbb G}(\mathcal A) = \Pr[\mathcal A \text{ wins}].$$

> [!remark] The description of the group
> The label $\mathbb G$ on the arrow stands for the description of the group, with $q$ and $g$: the adversary takes no input, so the challenger sends it.

## Claim

> [!definition] Discrete Logarithm Assumption
> The **discrete logarithm (DL) assumption** holds for $\mathbb G$ if $\mathsf{Adv}^{\mathsf{dl}}_{\mathbb G}(\mathcal A)$ is negligible for every efficient $\mathcal A$. `[Gal12 §20.1]` states it for an instance generator: no polynomial-time algorithm solves its instances except with negligible probability in the security parameter.

> [!remark] No decision variant
> DL is a search assumption: the decision variant of the problem — is $h \in \langle g \rangle$? — is trivial when $g$ generates $\mathbb G$ ([[knowledge/complexity/problem/group/Discrete Logarithm Problem#Decision Variant\|Discrete Logarithm Problem#Decision Variant]]). Its decisional relatives are about $g^{\alpha\beta}$, not about $\alpha$: [[knowledge/cryptography/assumptions/Computational Diffie-Hellman Assumption\|Computational Diffie-Hellman Assumption]] and [[knowledge/cryptography/assumptions/Decisional Diffie-Hellman Assumption\|Decisional Diffie-Hellman Assumption]], with $\mathrm{DDH} \leq_R \mathrm{CDH} \leq_R \mathrm{DLP}$ `[Gal12 Lemma 20.2.5]`.

> [!theorem] Random self-reducibility — solving a random instance with probability $\epsilon$ solves every instance with probability $\epsilon$
> **Scope**
> - $\mathbb G$: a cyclic group of prime order $q$, generated by $g$.
> - $\mathcal A$: an efficient algorithm with $\Pr[\mathcal A(u) = \mathrm{Dlog}_g(u)] = \epsilon$, over a uniform $u \in \mathbb G$ and the coins of $\mathcal A$.
>
> ---
> **Property** — there is an efficient algorithm $\mathcal B$ such that, for every $u \in \mathbb G$:
> - $\mathcal B(u)$ outputs `fail` or $\mathrm{Dlog}_g(u)$;
> - $\Pr[\mathcal B(u) = \mathrm{Dlog}_g(u)] = \epsilon$, over the coins of $\mathcal B$ only.
>
> `[BS §10.5]`

> [!proof] Algorithm $\mathcal B$
> - **Input**: $u \in \mathbb G$.
> - **Output**: $\mathrm{Dlog}_g(u)$ or `fail`.
> - **Steps**:
>     1. $\sigma \xleftarrow{\$} \mathbb Z_q$.
>     2. $u_1 \leftarrow u \cdot g^\sigma$.
>     3. $\alpha_1 \leftarrow \mathcal A(u_1)$.
>     4. If $g^{\alpha_1} \neq u_1$, outputs `fail`; else outputs $\alpha = \alpha_1 - \sigma$.
>
> $u_1$ is uniform in $\mathbb G$ whatever $u$ is, so $\mathcal A$ succeeds on it with probability $\epsilon$.

> [!remark] Why it matters
> If the problem is hard in the worst case, random self-reducibility makes it hard on average: within a fixed group, a random instance is as hard as any instance.
